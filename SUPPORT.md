# Getting help

- **Questions about using WeaveSharp:** ask in [Discussions](https://github.com/WeaveSharp/weavesharp/discussions) (Q&A), one question per discussion, with your WeaveSharp version and editor.
- **Something doesn't work as documented:** open a bug report with the issue form, once a release exists.
- **An idea or a missing outcome:** open a feature request with the issue form.
- **A security problem:** report it privately, as the [security policy](SECURITY.md) describes.
- **Anything else:** weavesharp@jasonfurr.com.

Nothing is released yet, so the first answers will be about plans rather than releases.
