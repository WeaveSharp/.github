# WeaveSharp

Visual authoring and debugging for ordinary C# projects, in the editors you already use. Read, write and debug C# as executable graphs while your C# source and project files stay the program.

## Editors

WeaveSharp is planned as extensions for Visual Studio Code, JetBrains Rider and Visual Studio over one shared .NET engine, with VS Code-compatible editors and remote workspaces qualified separately.
