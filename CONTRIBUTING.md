# Contributing to WeaveSharp

Thank you for your interest in WeaveSharp. It is at an early stage, and this guide says what helps most right now.

## Issues are welcome

Once a release exists, report a bug or ask for a feature with the issue forms; they ask for what we need to act on it. Ask questions about using WeaveSharp in [Discussions](https://github.com/WeaveSharp/weavesharp/discussions) (Q&A). Please search open and closed issues first, and keep source code, file paths and values you can't share publicly out of what you post.

## Outside pull requests are not accepted yet

Every change to WeaveSharp currently goes through one maintained process, with its own review and evidence for each claim the product makes. Until that process can take outside contributions, pull requests from outside the project are closed without review. An issue describing the change you want is the best way to propose it.

## Security

Never report a vulnerability in a public issue, discussion or pull request. Follow the [security policy](SECURITY.md).

## Conduct

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
